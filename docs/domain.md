# 景区资料语义

来源可以是主管部门、景区运营方或合作机构。每份原件有来源、字段说明与摘要，产品修订引用原件，交付时按领取方、用途和来源辖区核对许可。受理人员应能区别来源事实、内部编排和已交付凭据。

当前项目围绕公开等级目录的更正传播开展资料协作。正式公告、复核观察和运营材料各有发布主体；示例记录不代表真实景区状态。

## 公告版本链

主管部门的摘牌公告以只追加的方式留存三个层次的事实：

1. **公告来源**：每条公告版本登记发布来源（主管部门）、发布时间与编号，首发、更正、撤回各自成行。
2. **更正关系**：更正公告通过 `corrects` 指向被更正的版本，撤回通过 `withdraws` 指向被撤回的更正。关系只描述依据，不携带状态回写。
3. **产品版本与交付回执**：目录条目（asset）记录所依据的公告版本；数据产品按条目编排，回执在交付瞬间固化依据快照。

一条公告版本的当前效力由版本链折叠得出，而不是由可变状态位表达：未被取代的首发公告、未被撤回的更正公告属于有效集合；撤回更正后，被其取代的旧版本重新生效。这样更正若再次撤回，状态仍然可从完整链条重新推导，无法通过删除或倒放最后一条消息伪造。

已发出的旧回执保持不变，凭依据快照说明当时采用的公告版本，并由系统对照当前有效集合提示受影响景区；新领取在交付闸门处只接受当前可核实条目。工作人员按景区与领取方查询待重新确认清单，领取方领取含当前条目的新产品后该清单自动消解。
